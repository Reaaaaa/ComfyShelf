# ComfyShelf brand assets

`comfyshelf-mark.svg` is the scalable master mark. The icon contains three
workflow node chains beside three shelf markers; the lighter middle chain is the
workflow currently brought forward from storage.

`comfyshelf.ico` contains separate PNG frames at 16, 20, 24, 32, 48, 64, 128,
and 256 pixels. The 16–32 pixel frames use the optically adjusted drawing from
`gui/assets/comfyshelf-mark-small.svg`, rather than shrinking the master
mechanically. The individual rendered frames are kept in `icons/` for review.

The palette matches the application:

- background `#162126`
- outline `#31504D`
- archived nodes `#426D68`
- active workflow `#79AFA7`
